# Data — why this directory is empty

No raw data is committed to this repo. All inputs regenerate on demand from
projects #1 and #2 via `src/inputs.py`:

- **RUL backtest inputs** — out-of-sample RUL predictions for project #2's 20
  validation engines (NASA C-MAPSS FD001). Regenerated by
  `load_rul_backtest()`, which reuses project #2's tested `src/` modules.
- **Hydraulic fault inputs** — 1,764 held-out fault-state predictions from
  project #1's UCI hydraulic-rig pipeline. Regenerated by
  `load_hydraulic_predictions()`.

If your checkout of the portfolio uses different paths, set `P1` / `P2` in
`src/inputs.py`. See `docs/data_dictionary.md` for field definitions.
